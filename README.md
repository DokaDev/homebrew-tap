# DokaDev Homebrew tap

Homebrew formulae for [datarig](https://github.com/DokaDev/datarig), a terminal database client.

```sh
brew install dokadev/tap/datarig
```

or `brew tap dokadev/tap` first, then `brew install datarig`.

The formula for macOS and Linux (arm64 and x86_64) is `Formula/datarig.rb`. It installs the
release archives from [datarig's GitHub releases](https://github.com/DokaDev/datarig/releases).
datarig's release workflow updates it for every release. Release candidates are not published
here.
